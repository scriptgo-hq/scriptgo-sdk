# @scriptgo/types

TypeScript declarations of the SCRIPT//GO runtime API, for scripts written in TypeScript.

```bash
npm install https://github.com/scriptgo-hq/scriptgo-sdk/releases/download/v0.1.8/scriptgo-types-0.1.8.tgz
```

Part of the [SCRIPT//GO SDK](https://github.com/scriptgo-hq/scriptgo-sdk). Documentation:
[scriptgo.dev/docs](https://scriptgo.dev/docs). MIT licence.
